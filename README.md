# PorciPeso — Sistema de pesaje porcino por lote

Software propio que convierte un indicador serial económico (Lexus/Trumax Matrix, XK3190-A12E, GMT Tuxon S) en un sistema de análisis de pesaje porcino con paridad funcional al **PTM Advance Control Weight**.

- [docs/SPEC.md](docs/SPEC.md) — requisitos, modos de pesaje, algoritmo de conteo, datos y analítica.
- [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md) — capas, máquina de estados, modelo de datos, stack, testing.

**Estado:** spec en revisión. No construir hasta aprobación del cliente ("hazlo").
