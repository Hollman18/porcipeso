PorciPeso — pesaje porcino por lote

Un indicador serial económico manda el peso crudo por RS-232/RS-485. El software hace todo lo demás: cuenta los cerdos, registra cada evento con hora exacta, calcula la estadística del lote y la transmite en tiempo real. Paridad funcional con el PTM Advance Control Weight.

2 · Cómo funciona el conteo por promedio

El software vigila el stream y detecta escalones estables. Cada escalón se divide por el promedio vigente para saber cuántos cerdos subieron — y el promedio se auto-corrige con cada evento.

Peso acumulado del lote L-2407 — sesión de las 10:02
kg en plataforma vs. hora · cada punto = escalón estable registrado
● verde = escalón confirmado  ·  ● ámbar = requiere confirmación del operador (nunca se resuelve en silencio)
Paso 1 · Setear

Se pesa un cerdo solo. Ese valor queda como peso de referencia (102.5 kg).

Paso 2 · Detectar

El stream se estabiliza (varianza < umbral por 2 s) → el software registra el escalón con hora exacta.

Paso 3 · Contar

Δpeso ÷ promedio vigente, redondeado = cerdos que subieron. Si el residuo > 20 %, el evento queda ambiguo.

Paso 4 · Auto-corregir

El promedio se recalcula: acumulado ÷ conteo. Cada escalón calibra el siguiente — el error no se acumula.

n = round(Δpeso / promedio_móvil)   ·   promedio_móvil = peso_acumulado / conteo_total

3 · ¿Y si un cerdo se devuelve?

Depende de la geometría de la báscula. El software soporta ambas; el video de la operación real define cuál queda como principal.

Modo A · Plataforma que acumula

Los cerdos se quedan sobre la báscula. El conteo se deriva del peso neto en plataforma, así que la resta con signo lo resuelve sola:

+300 kg → +3 cerdos −101 kg → se bajó 1 +101 kg → volvió a subir

Neto del ciclo: cuenta exactamente una vez. La báscula no sabe mentir: el conteo nunca contradice los kilos que están encima.

Modo B · Báscula de paso

El cerdo cruza y sale (0 → peso → 0). La celda de carga no puede distinguir dirección — un cruce hacia atrás se ve idéntico. Tres defensas, en orden:

  1. Puerta antirretorno a la salida (fierro, recomendada): el cerdo no puede volver a pisar la báscula.
  2. Par de fotoceldas IR: corta A→B = adelante (+1); B→A = devuelto (−1). ~USD 50.
  3. Red de seguridad (siempre activa): peso repetido ±3 % en < 60 s → ámbar "¿posible devuelto?" + conciliación contra el conteo físico del camión al cerrar.

7 · Decisiones abiertas

  1. ¿El peso factura la venta? Si sí, el indicador debe ser Clase III certificado (Sensocar SCA31); si es control interno, el Matrix basta.
  2. PC de granja: ¿Windows existente o mini-PC dedicado (~USD 150, más robusto al polvo)?
  3. ¿Cuántas básculas simultáneas? Define si RS-485 multidrop entra al MVP.
  4. Ficha técnica PTM: está tras login del fabricante — si la consiguen, contrastamos paridad exacta.
